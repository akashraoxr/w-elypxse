# ELYPXSE DEVELOPMENTS // STEALTH MODE

> *Redefining Digital Experiences. Currently operating in stealth mode. An extraordinary digital landscape is being crafted.*

This repository contains the interactive "coming soon" landing page for Elypxse Developments. Built with modern web technologies, it acts as a digital teaser—featuring a highly interactive 3D topography background, custom GSAP animations, aggressive CSS glitch effects, and smart audio integration.

---

## ✨ Features

- **Interactive 3D Landscape:** A Three.js powered topographic wireframe grid that responds in real-time to user mouse movements.
- **Cinematic Animations:** Staggered text reveals and smooth element mounting powered by GSAP.
- **Aggressive Glitch Effects:** Custom CSS keyframe animations trigger random, violent screen tearing and RGB color splitting every few seconds.
- **Immersive Audio:** Integrated background music that gracefully handles modern browser autoplay restrictions by syncing with the user's first interaction, complete with a minimal toggle control.
- **Custom Cursor:** A GSAP-animated dot cursor that tracks movement and intelligently expands when hovering over interactive elements.
- **Modern Stack:** Built on the bleeding edge with **Next.js 16 (App Router)** and **React 19**.

## 🚀 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **UI Library:** [React](https://react.dev/)
- **3D Graphics:** [Three.js](https://threejs.org/)
- **Animations:** [GSAP](https://gsap.com/)
- **Styling:** Custom CSS & [Tailwind CSS v4](https://tailwindcss.com/)

## 🛠️ Getting Started

First, ensure you have Node.js installed, then clone the repository and install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to experience the landscape.

## 📂 Project Structure

- `src/app/` — Next.js routing, global styles (`globals.css`), and the main page assembly.
- `src/components/` — Modular React components (`Background.jsx`, `Cursor.jsx`, `AudioController.jsx`, etc.).
- `public/` — Static assets, including the browser tab icon and background music.
